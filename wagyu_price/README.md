# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリ
  - 開発内容を複数人で共有・公開するためにネット上に配置するリポジトリ

- ローカルリポジトリ
  - 開発者一人が使用するために自分のPC上に配置するリポジトリ


## プッシュとマージの違いは何でしょうか？
- プッシュ
  - ローカルのブランチの開発内容をリモートのブランチに反映させる

- マージ
  - 現在のブランチの開発内容を指定したブランチに反映させる

## コミットとプッシュの違い
- コミット
  - 変更した開発内容をブランチに保存すること

- プッシュ
  - 変更したローカルブランチの開発内容をリモートのブランチに保存すること


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- どこの部分をどう変更したか詳細に簡潔に書く


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- ローカルでマージするフロー
  - レビューをする人がいないのでバグがそのまま反映され重大な事故につながる可能性がある

- プルリクエストでマージするフロー
  - レビューをする人がバグを見つけ、事前に修正することができ、事故を未然に防ぎやすくなる


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- 先にマージされた変更内容を取り込む
- 後のマージしようとしている変更内容を取り込む
- どちらの変更内容も取り組む
